## 🧑‍💻 About Me

I'm a full-stack Software Developer based in **Pune, India** 📍.

I enjoy building web and mobile apps with modern tools, clean code, and thoughtful architecture, and I have a soft spot for **developer tools** that remove the boring, repetitive parts of the job.

- 🔭 Building **[gitmomos](https://gitmomos.spheo.online)**, which turns your Git commits into daily work reports
- 🐠 Maintaining **[QueryFish](https://www.npmjs.com/package/queryfish)**, which generates typed React Query hooks from OpenAPI specs
- 🌱 Exploring Go, AI-powered products, and monorepo tooling
- 💬 Ask me about React, TypeScript, NestJS, React Query, and full-stack architecture
- ⚡ Fun fact: I love tools that are simple, fast, and useful. Constantly exploring and learning is part of my DNA 💡
